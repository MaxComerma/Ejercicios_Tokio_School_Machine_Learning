# Python & Machine Learning Exercises

A collection of practical Python and machine-learning exercises completed during training at Tokio School.

The repository combines a curated **Machine Learning Highlights** section with a broader collection of supervised, unsupervised and model-interpretation exercises.

## Machine Learning Highlights

The main section contains the exercises I found most useful and representative of my work, including:

- Linear regression and housing datasets
- Cross-validation and model selection
- Decision trees and random forests
- KNN classification
- Logistic regression
- Digits classification / OCR
- Synthetic regression benchmarks

## Interpretación y Mejora de Modelos

Exercises focused on understanding and improving supervised learning models:

- SHAP and customer churn interpretation
- Random Forest
- Lasso and Ridge regression
- Feature importance and model evaluation

## Aprendizaje Supervisado

A broader collection of foundational exercises covering:

- Linear and logistic regression
- Decision trees and random forests
- Support Vector Machines
- Bayes theorem
- Normalization and regularization
- Gradient descent and cost functions
- Cross-validation

## Aprendizaje No Supervisado y Otros Temas

Additional topics explored during the course:

- K-Means and hierarchical clustering
- PCA
- Semi-supervised learning
- Forecasting
- APIs

## Tools

Python, pandas, NumPy, Matplotlib, scikit-learn and SHAP.

> This repository contains educational course exercises. Datasets are generally small and results should be interpreted as learning examples rather than real-world model performance.
